中国医疗出口 Opportunity Matrix

用于筛选“海外患者来华医疗 / 中国医疗服务与技术出海”的候选方向。核心看：价格差、标准化、疗程、随访、监管与获客难度。价格均为研究区间，不是报价；不同国家、医院、医生、术式与保险条件会显著改变实际价格。

候选领域
中位价格差 ≥ 2×
旅行适配度 ≥ 4/5
高/中高置信度价格数据

牙科：最像“标准化医疗出口产品”

优势：海外自费价格高、中国供应链成本低、临床技术成熟、结果可理解。

真正瓶颈：两阶段治疗与长期随访。因此商业护城河很可能是“上海治疗中心 + 海外合作牙医 + 英文病历/影像可携带”。

TMS：不应只按“医疗旅游”理解

限制：传统rTMS疗程通常较长；TMS主要是治疗工具，而不是单独诊断精神疾病的机器。

更大的路线：合规设备 + protocol + 医生培训 + 海外中心。若未来有成熟、获批的加速疗程，患者来华的适配度才会明显提高。

价格差倍数（中位数估算）

价格差 = 海外参考区间中点 ÷ 中国参考区间中点（中国价格按¥7.1/USD仅用于显示换算）。它不是利润率，也没有计入机票、酒店、渠道、保险、翻译与售后成本。

机会结构图：价格差 × 标准化

横轴：价格差；纵轴：标准化程度。圆越大代表客单价/复杂度越高。此图用于发现“值得进一步核验”的区域，不是投资评级。

如何读这个 Matrix

最容易形成医疗旅游产品的结构：高价格差 + 高标准化 + 短疗程 + 低随访难度。
不能只看价格差：肿瘤、精神/神经、关节置换等项目，即使价格差明显，也可能因为长期疗程、责任边界、跨境复诊而失去经济性。
第二条增长曲线：对TMS、康复、远程二诊等领域，应同步研究“设备 / protocol / 软件 / 医生培训 / 海外合作中心”的服务出口模式。
数据说明：海外价格主要使用美国自费或公开机构价格作为“高价市场基准”，并不代表全球统一价格。中国价格优先引用政府公开价、上海医院/市场公开价；找不到统一官方价格的领域使用研究性区间并标记较低置信度。国际医疗部价格通常高于本地公立普通门诊。所有价格都必须在进入商业计划前逐机构重新核验。
注意：本页面不是医疗建议，也不评价具体治疗是否适合个人。TMS、肿瘤治疗、整形、骨科等必须由有资质机构依据适应证、获批设备和临床规范实施。
